# Document format

A doc is an explanation as plain JSON: what is on screen (`nodes`, `edges`, `code`),
what the explanation is about (`state`), and named `steps` of ops that change both.
`sceneFromDoc(doc)` turns it into a Scene class, so a doc gets deep links, seeking,
text frames and traces like any hand-written scene. `traceScene()` reports the same
step names and `state`, so the authoring format and the trace format line up.

Types: `Doc`, `DocOp`, `DocNodeSpec`, `DocEdgeSpec` in [src/doc.ts](../src/doc.ts), exported from the package.
Example: [scenes/ring-buffer.doc.json](../scenes/ring-buffer.doc.json), generated by
[scenes/ring-buffer.doc.ts](../scenes/ring-buffer.doc.ts) (a loop beats 60 hand-written ops).

```json
{
  "title": "Ring buffer",
  "nodes": { "s0": { "kind": "slot", "label": "0", "at": [-2.55, 1.2] },
             "head": { "kind": "pointer", "label": "head", "color": "teal", "at": { "of": "s0", "dir": [0, 1], "buff": 0.1 } } },
  "edges": { "e1": { "from": "a", "to": "b", "label": "CONNECT", "curve": 0.6 } },
  "code":  { "lines": ["push(x) {", "  this.len++;", "}"], "at": [3.6, -1.6], "fontSize": 0.24 },
  "state": { "head": 0, "tail": 0, "len": 0 },
  "readout": { "keys": ["head", "tail", "len"], "at": [-6.4, 1.7] },
  "steps": [
    { "name": "push-a", "meta": { "op": "push" },
      "ops": [ { "focus": 1 }, [ { "add": { "id": "va", "kind": "value", "label": "a", "at": [0, -0.4] } }, { "set": { "len": 1 } } ] ] }
  ]
}
```

## Playback

1. Step `intro`: the title is written, then nodes fade in, edges draw, and the code
   panel and readout fade in.
2. Each step in `steps` begins (`await this.step(name, meta)`) and plays its ops in order.
   An op is one `play()`; an **array of ops plays together**. When that array both
   removes and adds (or replaces a note), the removals finish first and the
   additions play after, so two labels never crossfade.
3. Hold for `outro` seconds (default 1.5).

## Nodes

| kind | shape | label |
|---|---|---|
| `box` (default) | rounded rectangle, `width` (fits the label), `height` 1 | sans, centered |
| `state` | circle, `radius` 0.55 | mono, shrunk to fit |
| `slot` | square, `side` 0.9 | grey, below |
| `pointer` | short downward arrow | name above; placed by its arrow tip |
| `value` | none | mono |
| `text` | none | sans, `fontSize`, `weight` |

Colors are palette names (`blue teal green gold red grey yellow white purple orange`)
or any CSS hex.

`at` is `[x, y]` (frame is 16 × 9, origin at center, y up), a node id (that node's
center), or `{ "of": id, "dir": [dx, dy], "buff": b }`: beside that node, like `nextTo`.

## Edges

`{ from, to, label?, color?, curve?, labelAt?, labelDir? }`. Ends attach to the nodes'
borders (the circle for states). `curve` is the arc's turn in radians: positive travels
counterclockwise, bulging to the right of `from → to`; negative bulges left.

## Ops

| op | effect |
|---|---|
| `{ "focus": 3 }` / `{ "focus": null }` | move the code highlight to line 3, counting from 0 (optional `color`), or clear it |
| `{ "add": { "id", ...node } }` | create a node and fade it in |
| `{ "remove": "id" }` | fade a node out |
| `{ "move": { "id", "at" } }` | move a node |
| `{ "style": { "id", "color" } }` | recolor a node |
| `{ "indicate": "id" }` | pulse a node or edge (`color`, `scale`) |
| `{ "set": { "key": value } }` | change state; readout values animate |
| `{ "note": "text", "at"? }` / `{ "note": null }` | show a caption, replacing the previous one; or clear it |
| `{ "wait": 0.5 }` | hold |
| `{ "runTime": 0.8 }` | duration of this play (default 0.45 s) |

Keys are independent, so one op object may carry several, but one per object reads best.
